Rova User Guide/02. Access & Scope
SECTION 02 · ACCESS & SCOPE

Go to the right place before starting work

Logging in just takes you into Rova. Before viewing or updating data, confirm it is correct Project and Team on the top bar.

After this chapter, you will be able to
  • Log in using the method provided by your organization.
  • Identify key areas on the navigation bar.
  • Switch Project/Team and check the current scope.
  • Find Work Item, view notifications and open personal account.
  • Know what to check when you don't see Project or Team.
02.1

Log in to Rova

Use an already enabled organizational account. No need to ask for additional permissions just to open the login page.

BEFORE STARTING You need it
  • Organization email is active.
  • Permission to access at least one Project if you need to work in Project.
  1. 1
    Open the Rova page

    Access the address provided by the organization. The login page displays the field Email address.

  2. 2
    Choose a login method

    Enter email and select Continue, or select Sign in with Microsoft if your organization uses Microsoft.

  3. 3
    Authentication completed

    Follow the organization authentication screen. Do not share your password or authentication code with others.

  4. 4
    Check the results

    On success, Rova opens the page Home; Your name or profile picture appears in the upper right corner.

Don't have access yet?

Select link Contact your administrator on the login page or contact your organization's Workspace Admin. Do not use another account to bypass authorization.

02.2

Read the navigation bar

The header bar holds the main entry points. The menu displayed may vary according to your rights and scope.

1
Context selector

Indicates Workspace, Project and Team are selected; Used to change scope.

2
Business menu

Plan, Track, Quality and Portfolio open function groups; Home and Reports is the direct link.

3
Quick search

Find Work Item from the top bar and open the appropriate result directly.

4
Personal tools

Opens notifications, help, Settings and account menus.

02.3

Select the correct Project and Team

This is a step that needs to be repeated every time you switch to a different product or group.

  1. 1
    Open context selector

    Select Workspace display area and line Project · Team in the upper left corner.

  2. 2
    Select Project

    The list only displays Projects you are allowed to access. Open the Project you need to work on to see available Teams.

  3. 3
    Select Team or All Teams

    Select a specific Team when working with that team. All Teams is an Admin view scope, not a Team to assign to Work Item.

  4. 4
    Check the title again

    After choosing, Rova takes you home Home. Confirm the line Project · Team changed before continuing.

EXPECTED RESULTS Home opens in the new scope

Data by Project/Team is reloaded. Content from the previous scope is not retained as current data.

Changing Team can cause the Owner list to change

Who can be selected as Owner depending on Project, Team, rights and valid membership. Please choose the correct Team before creating US or Defect.

02.4

Read the Home page

Home is a quick checkpoint after logging in or changing scope.

IndexDescription
Active ProjectsNumber of active Projects that your account is allowed to view.
Open Work ItemsNumber of unfinished Work Items within the currently displayed data scope.
Active SprintsNumber of active duty cycles.
Blocked ItemsNumber of Work Items in status Blocked.
Open DefectsDefect number has not completed processing.
Assigned to MeNumber of Work Items being assigned to your account.
My Work

Work Items assigned to you. Select All to open the full list.

Recent Activity

Recent activity your account is allowed to see.

Project Health

Overview Project, Iteration is running, progress and bugs are open.

Do not use a single metric to confirm the scope

Please read the context selector and breadcrumb first. Some Home tabs may aggregate broader data than Team is choosing at your discretion.

02.5

Search, notifications, and accounts

These three tools are always located on the top bar and serve logged in users.

⌕

Search work items

  1. Enter the Work Item name ID or keyword.
  2. Read the ID and title in the suggestion list.
  3. Select the result to open the details page.
◎

Notifications

  1. Select the bell icon.
  2. Use Unread only when you only want to view unread items.
  3. Select View all to open the Notifications page.
HV

Personal account

  1. Select name or avatar.
  2. Open My profile or Settings when needed.
  3. Select Sign out to end the session.
02.6

Handling when Project or Team is not visible

Check in the order below before concluding that data is lost.

01
Project not found

Open the context selector again and check the correct Workspace. If Project still does not appear, ask Workspace Admin to check the account's Project Access.

02
See Project but not Team

Admin works at All Teams. The Editor only sees the assigned Team; Ask Workspace Admin to check Team membership.

03
Direct path denied

Return to Home, select a Project/Team you are allowed to access and then reopen the function from the menu. If you still need that data, contact Workspace Admin.

05
The page still shows the old scope

Read the context selector again, wait for the data to finish loading, and refresh the page once. Do not update the Work Item until the scope header is correct.

WHEN CONTACT SUPPORT Send all three information

Account email, Project/Team name to access and screenshot of context selector or message being displayed. Do not send passwords or authentication codes.
