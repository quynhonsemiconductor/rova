00.1

Before you start

Three things to help you avoid manipulating the wrong data or finding the wrong function.

1

Check the selected scope

Look at the upper left corner and confirm it is correct Workspace · Project · Team. The Work Items you can see and the available Owners depend on this scope.

2

Know your rights

You might be Workspace Admin, Admin of Project, or Editor in Team. Buttons and displayed data may vary.

3

Select the correct target

Go from what you want to get done: create tasks, create plans, update Tasks, view reports, or administer. There is no need to read the entire document sequentially.

Permissions note

Role names such as PM, BA, Developer, or QA are not permission names in Rova. Operational permissions are determined by Workspace, Project and Team.
